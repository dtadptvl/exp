# Global Prime / disposable sub (Kilo CLI)

Windows: double-click `setup.cmd` (Kilo installed); read `AI_CONFIG_MERGE_GUIDE.md`, apply minimal human config change, then run `kilo debug agent prime`, `kilo debug agent sub`. Run in any Git project with `kilo run --auto --agent prime "your request"`; for a supervised headless run: `python <package>/watch.py --wall 3600 --idle 600 kilo run --auto --agent prime --format json "your request"`. Interrupting the Kilo process cancels native child Task; record STALLED in state and start fresh. No promise of unattended quality without real provider access. Uninstall: `powershell -File install.ps1 -Uninstall`. Package has no runtime dependency on reference ZIP.

`state.py refresh` prints a small packet; `ack` acknowledges reviewed Git delta, invalidating impacted task nodes; `check` exits 1 on divergence. In each project `.prime/state.json` is created lazily by `ack`; Prime edits state to record task graph/contract, never Sub. `tasks` maps IDs to `{status,produces:[paths],consumes:[paths],depends_on:[IDs],verified_by:[IDs],assumes:[IDs],evidence:[refs]}`. `active` names the task; store the task contract there or under its ID. `git` is branch, HEAD and porcelain status, not a history duplicate. Git is source of code truth. Reconcile at every human prompt and after Sub return. `ack` does not resolve semantic assumptions automatically: Prime assesses which affected edges remain valid and rechecks only affected successors. If unrelated unknown paths changed, inspect before acknowledging.

Native Kilo owns agent discovery, child sessions, compaction, Task execution and permissions. `watch.py` bounds outer CLI wall/inactivity time on **completed tool results**, not reasoning text or step count. This is an optional whole-invocation watchdog, not a per-child timeout; parent cancellation can discard unfinished Prime output. Retry at most once per unchanged failure signature before explicit replan; never overwrite human files. Serial workers by default: shared tree prevents safe concurrent writes without coordination.

Contract keys: `task_id, objective, in_scope, out_of_scope, acceptance, hard_constraints, relevant_files_symbols, dependencies, verification, stop_condition`. Sub returns `task_id,status,summary,files_changed,verification,evidence,risks,out_of_scope_findings,next_required_action`. Test: `python tests/check.py`. No package dependencies beyond Python stdlib, Git, PowerShell and Kilo CLI.
